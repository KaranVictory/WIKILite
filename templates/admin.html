{% elif tab == 'acl' %}

기본 접근 제어 목록(ACL)

문서별 ACL이 있으면 문서별 설정이 우선합니다.

나무위키의 접근 제한 단계에서 착안한 정책입니다. 신규 가입자 제한은 일반적으로 가입 후 15일을 기준으로 하며, 이 위키에서는 일수를 직접 조절할 수 있습니다. 실제 나무위키의 모든 인증·운영진 정책을 복제한 것은 아닙니다.

{% for action, label in [('read','읽기 권한'),('edit','편집 권한'),('discuss','토론 권한')] %}

{{ label }}

허용 기준이 가입 기간일 때 사용합니다. 예: 7일은 1주, 14일은 2주, 15일은 나무위키의 대표적인 신규 가입 제한 기준입니다.
{% endfor %}

정책 설명

  • 누구나: 로그인하지 않은 사용자도 허용합니다.
  • 로그인한 사용자: 계정에 로그인해야 합니다.
  • 가입 후 일정 기간 경과: 계정 생성일로부터 지정한 일수가 지나야 합니다.
  • 해당 문서 기여자: 현재 계정이 해당 문서에 한 번 이상 편집 기록을 남겨야 합니다.
  • 관리자만: 관리자 계정만 허용합니다.

관리자는 ACL에 의해 잠기지 않도록 항상 우회할 수 있습니다. 계정/IP 차단은 별도로 적용되며, 일반 사용자의 읽기는 차단하지 않고 편집·토론·가입을 제한합니다.
