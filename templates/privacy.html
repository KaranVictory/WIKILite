회원가입으로

이 위키는 계정 보안과 악용 방지를 위해 IP 주소를 처리합니다. IP 주소는 네트워크 상황에 따라 여러 이용자가 공유할 수 있으므로, 차단 시 무관한 이용자에게 영향이 갈 수 있습니다.

1. 처리하는 정보

  • 계정 정보: 아이디, 비밀번호 해시, 가입 시각, 약관 및 개인정보 처리 안내 동의 시각과 버전.
  • IP 정보: 회원가입 IP, 로그인한 IP, 로그인 이후 인증된 요청에서 확인한 최근 IP.
  • 로그인 기록: 계정 아이디, 성공한 로그인 시각, 해당 요청에서 확인한 IP 주소.
  • 회원가입 기록: 가입 완료 계정명, 가입 시각, 해당 요청에서 확인한 IP 주소.

비밀번호 원문은 저장하지 않고 해시 형태로 저장합니다. 현재 버전은 실패한 로그인 시도의 IP는 별도 로그인 기록으로 저장하지 않습니다.

2. 처리 목적

계정 보안 유지, IP 주소당 최대 5개 계정 제한, 부정 이용·스팸·문서 훼손 대응, 계정 및 IP 차단 관리, 보안 사고 확인을 위해 사용합니다. IP 기록은 관리자만 볼 수 있습니다.

3. 보관 기간

  • 성공한 로그인 기록의 IP와 시각: 최대 {{ login_log_retention_days }}일. 앱이 실행되어 요청을 처리할 때 만료된 기록을 하루에 한 번 정리합니다.
  • 회원가입 IP 감사 기록: 최대 {{ registration_log_retention_days }}일. 만료된 기록은 앱 요청 처리 시 하루에 한 번 정리합니다.
  • 회원가입 IP: IP 주소당 최대 5개 계정 제한과 계정 보안·차단 관리에 사용하며, 계정 정보와 함께 보관됩니다. 운영자가 계정 및 관련 정보의 보유 필요가 없다고 판단해 삭제할 때까지 유지됩니다.
  • 최근 IP: 계정 보안과 차단 관리 목적상 계정 정보와 함께 보관되며, 운영자가 삭제하거나 계정 관련 정보의 보유 필요가 없어질 때까지 유지됩니다.
  • 약관 동의 기록과 문서 편집 동의 기록: 해당 계정 및 편집 기록의 이력 확인을 위해 데이터베이스에 보관됩니다.

4. 접근 및 공개

로그인 IP 기록은 일반 문서에 공개하지 않고 관리자 제어판에서만 열람하도록 설계되어 있습니다. 단, 서버·호스팅 제공자의 기술 로그에도 접속 정보가 기록될 수 있으며 그 보관·처리는 해당 제공자의 정책을 따를 수 있습니다.

5. 프록시 및 실제 IP

리버스 프록시를 사용하는 호스팅에서는 신뢰할 수 있는 프록시 설정이 올바르지 않으면 이용자의 실제 IP 대신 프록시 IP가 기록될 수 있습니다. 운영자는 신뢰하는 프록시 환경에서만 해당 설정을 켜야 합니다.

6. 문의 및 유의 사항

이 위키의 운영자에게 개인정보 처리에 관한 문의를 할 수 있습니다. 이 문서는 프로그램에 기본 포함된 안내문이며, 실제 공개 전에 운영자 연락처, 관련 법률, 호스팅 제공자의 로그 처리 및 보관 환경에 맞게 검토·수정해야 합니다.
