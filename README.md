# NamuLite Wiki v0.16 — Vercel + PostgreSQL 배포

한글 문서 제목이 URL 인코딩 문자열로 저장된 경우 자동 정리하는 수정이 포함되어 있습니다. 나무마크와 나무위키식 문서 흐름을 참고해 별도로 작성한 소규모 위키 엔진입니다. Python 3.11 이상을 권장하며 Python 3.13도 사용할 수 있습니다. **나무위키/the seed 엔진의 완전한 복제품은 아니며, 모든 문법과 예외 동작이 동일하다고 보장하지 않습니다.**

## 실행 방법

Windows에서는 압축을 푼 다음 `run_windows.bat`을 실행하세요. 이 파일은 `py` 명령이 없어도 `python` 명령을 찾고, 프로젝트 전용 `.venv`를 만든 뒤 필요한 패키지를 설치합니다.

직접 실행하려면:

```bat
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python app.py
```

브라우저에서 `http://127.0.0.1:5000`을 열고 계정을 만드세요. 새 위키의 첫 계정은 소유자이자 관리자입니다. 기본 데이터베이스는 `instance/wiki.db`입니다.

## 현재 위키 기능

- 문서 생성·편집·미리 보기, 최근 변경(삭제 기록 포함), 검색, 문서별 토론
- 일반 문서의 계층형 하위 문서: `DDS/DDS의 장비`, `DDS/DDS의 장비/레이더` 형태; 상위 경로 및 접이식 `하위 문서 찾기`에서 모든 단계 하위 문서 표시
- 사이드바의 별도 문서 만들기 항목 제거; 검색 결과가 없으면 문서가 없다는 안내와 생성 버튼 표시
- 편집 역사와 과거 버전 열람, 변경 내용 비교. 문서 삭제 시 편집 이력과 삭제자·삭제 시각을 별도 보존하며 역사와 최근 변경에 삭제 사건을 표시
- 회원가입·로그인, 비밀번호 해시, CSRF 토큰
- 분류 목록과 분류별 문서 목록
- 문서별 `#redirect` 리다이렉트
- 편집 화면의 이미지 업로드: PNG, JPG/JPEG, GIF, WEBP (로컬 최대 8MB, Vercel 최대 3MB/회 요청 제한 적용)
- 반응형 화면과 라이트/다크 모드 전환 버튼(로그인 여부와 무관, 브라우저에 선택 저장)
- 관리자 전용 탭: 위키 이름/소개/설명, 기본·링크 색상, 배경 스타일, 로고 업로드 변경
- 관리자 개요 통계, 사용자 역할(관리자/일반 사용자) 관리, 계정별 경고 누적 횟수·최근 내역, 접이식 계정 차단 UI, 최근 문서 관리 목록
- 전역 ACL 설정: 읽기·편집·토론 별 허용 기준 설정
- 문서별 ACL 탭: 기본 설정 상속, 누구나/로그인 사용자/가입 기간/문서 기여자/관리자 정책
- 가입 후 경과 일수 직접 설정(예: 7일·14일·15일)
- 계정 차단 시 가입 IP와 최근 IP에도 같은 기간의 IP 차단을 자동 적용
- 성공한 로그인 시 IP 주소와 UTC 시각을 기록하며, 관리자 전용 `로그인 IP 기록` 탭에서 확인
- 회원가입 성공 시 별도 감사 테이블에 가입 계정명·가입 IP·시각을 기록하며, 관리자 전용 `회원가입 IP 기록` 탭에서 확인 (180일 보관, 기존 계정은 보존된 가입 IP가 있을 경우 기록 복원)
- 계정 가입 시 `사용자:계정명` 사용자 문서가 자동 준비됩니다. 문서는 기본적으로 공개 열람되며, 사용자 본인과 관리자는 해당 문서를 편집할 수 있음
- 개인 사용자 문서는 단일 문서로만 운영하며 `사용자:계정명/하위문서` 생성과 편집을 차단
- 로그인 기록과 회원가입 IP 감사 기록은 각각 최대 180일 보관하며, 앱 요청 처리 시 하루 한 번 만료 기록 자동 정리
- 회원가입 시 이용약관 및 IP 처리 안내에 대한 필수 동의 체크박스와 버전/시각 기록
- 문서 저장 시 CC-BY-NC-SA 2.0 KR 라이선스와 생성형 AI 정책 동의가 필수이며, 동의 시각과 정책 버전을 편집 이력에 기록
- `/terms` 이용약관·생성형 AI 정책, `/privacy` 개인정보 처리 안내 페이지
- 수동 IPv4/IPv6 차단, 기간 설정, 차단 만료/해제 이력 및 관리자별 사유 기록
- IP 주소당 최대 5개 계정 가입 제한. 계정별 가입 IP로 누적 관리하며 180일 가입 감사 로그 정리와 별개로 제한 횟수 유지
- 관리자 경고 시스템: 사유가 포함된 경고 발행, 미확인 경고의 로그인 직후 팝업, 사용자 경고함과 확인 처리
- 하위 문서 찾기 버튼으로 해당 문서의 모든 단계 하위 문서를 접힌 목록에서 펼쳐 확인
- 관리자 경고 발행과 경고 기록은 사용자 관리 탭에 통합되어 있습니다. 별도 경고 관리 탭은 없습니다.
- 관리자와 별도의 소유자 권한. 소유자는 PostgreSQL 연결 테스트 설정과 백업을 관리하며, 소유자 지정은 현재 소유자만 가능
- 문서 화면에서 관리자/소유자가 문서를 삭제할 수 있으며, 토론·ACL은 삭제되지만 편집 이력은 삭제 문서 역사에 보존 (하위 문서는 별도로 유지)
- 소유자 전용 PostgreSQL 호스트/포트/DB/사용자/암호화된 비밀번호/SSL 모드 입력 및 `SELECT 1` 연결 테스트
- Vercel 배포 시 `DATABASE_URL` 환경 변수를 통한 PostgreSQL/Neon 주 데이터 저장소, PostgreSQL 내부의 업로드 이미지 저장
- PostgreSQL 모드의 ZIP 백업/복원, 기존 SQLite ZIP 백업의 PostgreSQL 이전 지원
- Vercel 환경 변수가 없을 때 임시 SQLite로 잘못 실행되어 데이터가 유실되는 상황을 방지
- 소유자 전용 수동 백업: 로컬 SQLite 또는 PostgreSQL 스냅샷과 업로드 이미지를 ZIP으로 내보내고, 보관 기간(1~3650일)에 따라 만료 백업을 정리
- 화면 테마와 경고 팝업·관리자 사용자 관리: [THEME_AND_WARNINGS_GUIDE.md](THEME_AND_WARNINGS_GUIDE.md)
- 상세 안내: [OWNER_AND_BACKUP_GUIDE.md](OWNER_AND_BACKUP_GUIDE.md)
- 설정 단계: [ACCESS_CONTROL_GUIDE.md](ACCESS_CONTROL_GUIDE.md)

## 나무마크 지원 범위

대표 문법과 예시는 [NAMUMARK_GUIDE.md](NAMUMARK_GUIDE.md)를 참고하세요. 현재 파서가 지원하는 주요 항목은 다음과 같습니다.

- 서식: 굵게, 기울임, 밑줄, 취소선, 위·아래 첨자, 글자 크기·색상
- 내부/외부 링크, 문단 앵커, 중복 문단 앵커, 분류
- 문단 제목, 목차, 수평선, 인용문, 중첩 목록, 주석
- 기본 표, 너비/색상/정렬, 셀 가로·세로 병합
- 코드 블록, `#!wiki`/`#!style` 본문 래퍼, 접기 문법
- 각주와 명명 각주 재사용
- 날짜·나이·D-Day·앵커·루비 매크로
- 업로드된 이미지의 `[[파일:...]]` 문법
- YouTube/Vimeo 임베드, 나머지 일부 영상 매크로의 외부 링크

분류는 문서 본문 안에 링크로 표시하지 않고 문서 하단 분류 영역에 표시합니다. 보안상 원문 HTML은 실행하지 않으며 `#!wiki`/`#!style`에 임의로 입력한 CSS도 그대로 적용하지 않습니다.

## 약관 동의, 생성형 AI 정책과 IP 기록

- 회원가입은 이용약관 및 개인정보 처리 안내 체크박스 두 개에 모두 동의해야 완료됩니다. 동의 시각과 문서 버전이 계정 데이터에 저장됩니다.
- 로그인 IP 기록에는 성공한 로그인만 저장됩니다. 실패한 로그인 IP는 별도 로그인 기록으로 저장하지 않습니다. 로그 기록은 최대 180일이며, 가입 IP와 마지막 접속 IP는 계정 보안/차단 대응을 위해 계정 정보에 남습니다.
- 문서 저장은 편집 화면의 기여 동의 체크박스를 필수로 요구합니다. 동의 버전과 시각은 각 revision에 저장됩니다. 미리 보기와 이미지 업로드는 동의를 요구하지 않습니다.
- 생성형 AI 사용 정책은 원칙적으로 문서 생성/편집에 AI 생성 콘텐츠를 기여하는 일을 금지하며, 일부 교정, 단순 번역, 비텍스트 미디어의 텍스트 변환, 외부 출처 후보 조사 같은 제한적 예외와 표시 요건을 정책 페이지에 설명합니다.
- 이 프로젝트에 기본 포함된 이용약관/개인정보 안내는 예시 텍스트입니다. 공개 운영 전에 운영자 연락처, 실제 호스팅 로그 처리, 개인정보 보유 기간 및 적용 법률에 맞게 검토·수정해야 합니다. 동의 체크박스 자체만으로 모든 법적 의무가 충족되는 것은 아닙니다.

## 환경 변수

| 변수 | 용도 | 기본값 |
|---|---|---|
| `SECRET_KEY` | 세션 서명 및 저장된 PostgreSQL 비밀번호 암호화 | 로컬은 `instance/secret_key`, Vercel은 필수 환경 변수 |
| `WIKI_NAME` | 초기 사이트 이름 (관리자 설정이 저장되면 저장된 이름 우선) | `나무라이트 위키` |
| `DATABASE_PATH` | SQLite 파일 경로 | `instance/wiki.db` |
| `COOKIE_SECURE` | HTTPS 전용 쿠키 (`1`/`0`) | `0` |
| `TRUST_PROXY` | 신뢰하는 리버스 프록시 뒤에서 실제 클라이언트 IP 사용 (`1`/`0`) | `0` |
| `DATABASE_URL` | 설정 시 PostgreSQL/Neon을 주 저장소로 사용 | 미설정 시 SQLite |

Vercel 배포에는 `DATABASE_URL`과 고정된 `SECRET_KEY`가 반드시 필요합니다. 자세한 내용은 [VERCEL_DEPLOY_GUIDE.md](VERCEL_DEPLOY_GUIDE.md)를 참고하세요.

## Render 등 배포

GitHub 저장소를 연결하고 Build Command를 `pip install -r requirements.txt`, Start Command를 `gunicorn app:app`으로 설정할 수 있습니다. 공개 운영에서는 `SECRET_KEY`와 HTTPS 설정을 확인하세요. Render 설정은 `TRUST_PROXY=1`로 지정되어 있습니다. 다른 환경에서 `TRUST_PROXY=1`을 켤 때에는 앱이 신뢰할 수 있는 프록시 뒤에서만 접속되도록 구성하세요.

Vercel 배포: [VERCEL_DEPLOY_GUIDE.md](VERCEL_DEPLOY_GUIDE.md)의 안내대로 `DATABASE_URL`을 설정하면 PostgreSQL/Neon에 문서·계정·이미지를 보관합니다. Vercel 환경에서는 파일 시스템에 쓰는 SQLite 방식을 사용하지 않습니다.

## 안전한 운영을 위한 주의

- 테스트용으로 만든 엔진입니다. 공개 전에 백업, 스팸 방지, 요청 제한, 권한 관리, 영구 저장을 보강하세요.
- 계정 차단은 해당 계정의 가입 IP와 마지막 접속 IP에도 같은 기간 적용됩니다. IP 차단은 같은 공인 IP를 공유하는 다른 이용자에게도 영향을 줄 수 있으므로 차단 사유와 기간을 신중히 설정하세요.
- IP 차단은 현재 정확한 IPv4/IPv6 주소 기준이며 네트워크 대역(CIDR)은 지원하지 않습니다. 읽기 ACL은 별도 설정이 없으면 허용하고, 차단 상태에서는 편집·토론·신규 가입을 제한합니다.
- 업로드는 확장자와 파일 시그니처를 검사하지만, 이미지 업로드는 저장 공간을 사용합니다.
- 문서 원문은 HTML로 실행하지 않습니다. 안전하지 않은 HTML/CSS 실행 기능은 호환성보다 보안을 우선해 제한했습니다.

### v0.8.1 하위 문서 버튼 표시 개선

일반 문서에는 작은 `하위 문서 찾기` 버튼이 표시되며, 누르면 모든 단계의 읽을 수 있는 하위 문서가 접이식 목록으로 펼쳐집니다. 하위 문서 생성은 로그인 및 상위 문서 읽기·편집 ACL을 통과해야 합니다.


### v0.8.2 변경 사항
- 상단 로고, 사이드바 `대문`, 오류 페이지의 `대문으로` 링크는 이제 `대문` 문서(`/w/대문`)로 이동합니다.

### Vercel 및 PostgreSQL 지원 (v0.11)
Vercel에서는 `DATABASE_URL`로 PostgreSQL/Neon을 주 데이터 저장소로 사용합니다. 문서·계정·수정 이력·설정·업로드 이미지가 PostgreSQL에 저장되며 백업은 `namulite_backups` 테이블에 보관됩니다. 이전 SQLite ZIP 백업을 PostgreSQL 모드로 가져오는 기능도 포함됩니다. 배포 및 환경 변수 설정은 [VERCEL_DEPLOY_GUIDE.md](VERCEL_DEPLOY_GUIDE.md)를 참고하세요.
